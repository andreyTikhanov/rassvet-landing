\# Rassvet Landing



Статический frontend лендинга сбора средств

на проведение съезда партии «Рассвет».



\## Stack



\- HTML5

\- CSS3

\- Vanilla JavaScript



\## Structure



\- `index.html` — landing page

\- `css/` — section styles

\- `js/main.js` — navigation, progress, requisites clipboard

\- `assets/` — logos and images



\## Local run



Open with VS Code Live Server.
